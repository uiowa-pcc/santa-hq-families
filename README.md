# Your Christmas Lights Hunt photos

Upload photos into this folder via GitHub → Add file → Upload files.

Recommended filenames are lowercase, e.g. `mickey-mouse.jpg` or `the-grinch.png`.
Filenames like `Mickey Mouse.JPG` are normalized automatically too.
Santa HQ automatically matches a picture to the clue with the same name.
You may use JPG, PNG or WebP. To replace an existing photo, replace its file.

Suggested filenames for all 14 new Mega Hunt clues:

- `giant-inflatable.jpg`
- `giant-ornament.jpg`
- `nativity-scene.jpg`
- `light-up-mailbox.jpg`
- `mickey-mouse.jpg`
- `winnie-the-pooh.jpg`
- `the-grinch.jpg`
- `snoopy.jpg`
- `olaf.jpg`
- `music-synced-lights.jpg`
- `holiday-projector.jpg`
- `chasing-light-pattern.jpg`
- `light-tunnel-or-arch.jpg`
- `lights-spelling-a-word.jpg`

File extensions may instead be `.png`, `.webp`, or `.jpeg`. Use ONE image
per clue, so avoid keeping `.jpg` and `.png` versions of the same name.

Tip: upload images that you photographed or have permission to use;
this GitHub repo is public even if your Santa HQ family data is private.
